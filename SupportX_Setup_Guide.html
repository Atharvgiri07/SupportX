1 Extracting the Zip File

Follow these steps to extract your project files properly on Windows:

  1. Locate the SupportX.zip (or project zip file) on your computer.
  2. Right-click the zip file and select Extract All...
  3. Set the destination folder path to your target directory (e.g., D:\project\SupportX).
  4. Click Extract.
  5. Ensure your directory structure looks like this: 
    D:\project\SupportX\
├── backend\
│   └── backend4\
│       ├── server.js
│       ├── package.json
│       └── .env
└── frontend\
    ├── package.json
    └── src\

2 Prerequisites Check

Ensure you have the required runtime installed on your machine:

  • Node.js (v18.0 or higher): Verify by opening Command Prompt or PowerShell and running: 
    node -v
  • npm (v9.0 or higher): Verify by running: 
    npm -v

3 Backend Configuration & Startup

Run the backend API server (Node.js + Express + MongoDB Atlas):

  1. Open a Terminal / Command Prompt window.
  2. Navigate to the backend folder: 
    cd D:\project\SupportX\backend\backend4
  3. Install backend dependencies: 
    npm install
  4. Verify your .env configuration file at D:\project\SupportX\backend\backend4\.env: 
    PORT=5000
MONGO_URI=mongodb+srv://atharvgiri07:giri1234@cluster0.9c3ezdr.mongodb.net/smartdesk?retryWrites=true&w=majority&appName=Cluster0
JWT_SECRET=replace_this_with_a_long_random_string
JWT_EXPIRE=7d
GEMINI_API_KEY=your_gemini_api_key_here
CLIENT_URL=http://localhost:5173
  5. Start the backend server: 
    node server.js
✅ Expected Backend Output: 
🖥️  SmartDesk server running on port 5000
✅ MongoDB Connected: ac-ppqpmzv-shard-00-00.9c3ezdr.mongodb.net

4 Frontend Setup & Running Vite

Run the frontend client application (React 18 + Vite):

  1. Open a NEW / Second Terminal window (keep the backend terminal running).
  2. Navigate to the frontend folder: 
    cd D:\project\SupportX\frontend
  3. Install frontend dependencies: 
    npm install
  4. Start the Vite development server: 
    npm run dev
✅ Expected Frontend Output: 
  VITE v5.4.21  ready in 867 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: http://10.144.1.60:5173/

6 Common Troubleshooting

  • Error: Port 5000 is already in use:

    Kill the existing node process using Command Prompt:

    taskkill /f /im node.exe
  • MongoDB Connection Failed:

    Ensure your internet connection is active and your IP is whitelisted in MongoDB Atlas Network Access.

  • Module Not Found Error:

    Re-run npm install in both `backend4` and `frontend` folders.
